```
             │                                       │

             ▼                                       ▼
      Scaled: 255                                   0
             │                                       │
             ▼                                       ▼

      │ Persistence (10s) - Must persist before triggering   │
      │ ┌──────────┬──────────┬────────────────┬──────────┐ │
      │ │  0-10s:  │ 10s+:    │   After stop:  │          │ │
      │ │  Output  │ Output   │   Output       │          │ │
      │ │  = 0     │ = 255    │   = 0          │          │ │

             │                  │                    │

      │ Timeout (60s) - Reset after no activity              │
      │ ┌──────────────────────┬───────────────────────────┐ │

      │ │  Maintain value      │  Force output = 0         │ │
      │ └──────────────────────┴───────────────────────────┘ │
      └──────┬───────────────────────────────────────┬────────┘
             │                                       │

        To DMX Channel                          Reset to 0
```

## Temperature Processing Example

```
┌────────────────────────────────────────────────────────────────┐
│     Temperature Sensor Pipeline (Noise Filtering)              │
└────────────────────────────────────────────────────────────────┘

Raw readings: 25.0  25.2  45.0  25.1  25.3  26.0  26.2
              │     │     │     │     │     │     │
              ▼     ▼     ▼     ▼     ▼     ▼     ▼
         ┌────────────────────────────────────────────┐
         │ MedianFilter (window=5)                    │
         │ • Removes spike (45.0)                     │
         │ • Sorts: [25.0, 25.1, 25.2, 25.3, 45.0]   │
         │ • Returns: 25.2 (median)                   │
         └────────┬───────────────────────────────────┘
                  ▼
Filtered: 25.0  25.1  25.2  25.2  25.2  25.8  26.0
                  │     │     │     │     │     │
                  ▼     ▼     ▼     ▼     ▼     ▼
         ┌────────────────────────────────────────────┐
         │ EMA (α=0.3)                                │
         │ • new_val = α×input + (1-α)×prev           │
         │ • Smooths remaining variations             │
         └────────┬───────────────────────────────────┘
                  ▼
Smoothed: 25.0  25.0  25.1  25.1  25.1  25.3  25.5
                  │     │     │     │     │     │
                  ▼     ▼     ▼     ▼     ▼     ▼
         ┌────────────────────────────────────────────┐
         │ RangeMapping (-40°C to 100°C → 0 to 255)  │
         │ • normalized = (val - (-40)) / (100-(-40)) │
         │ • mapped = normalized × 255                 │
         └────────┬───────────────────────────────────┘
                  ▼
DMX:      182    182    183    183    183    184    185
          │      │      │      │      │      │      │
          ▼      ▼      ▼      ▼      ▼      ▼      ▼
    ┌──────────────────────────────────────────────────┐
    │         Final DMX Output (Channel 0)             │
    └──────────────────────────────────────────────────┘
```
